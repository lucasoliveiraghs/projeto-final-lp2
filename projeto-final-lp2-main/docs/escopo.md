# Problema, público-alvo, descrição de cada página e o que contém em cada uma delas

Esse é um site que reune as informações básicas do universo de Ben 10 clássico, de facil acesso e estética personalizada para a melhor experiência do usuário.

- Home -> Essa página introduz o site e contém a parte mais chamativa do site.
- História -> Essa página resume a história principal do universo de Ben 10
- Personagens -> Essa página introduz e resume os personagens principais, "heróis" e vilões
- Quiz -> Nessa página, o usuário poderá realizar dois quizes
- Questionário -> Nessa página o usuário dará seu feedback e sugestões para o site
- Créditos -> Essa página introduzirá os criadores do site 
- Aliens -> Essa página é especial para cada alien, detalhando cada alien
